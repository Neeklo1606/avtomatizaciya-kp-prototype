## Корневая причина «мёртвых» кнопок

Найден и устранён критичный дефект: затемняющий слой `.scrim` имел прозрачность `0`, но **не** `pointer-events:none`.
После первого открытого диалога невидимый слой оставался поверх страницы и перехватывал **все** клики.
Именно это давало «мёртвые» кнопки на скриншотах приёмки.

```css
/* было */
.scrim{ ...; opacity:0 }
.scrim.on{ opacity:1 }
/* стало */
.scrim{ ...; opacity:0; pointer-events:none }
.scrim.on{ opacity:1; pointer-events:auto }
```
