## 7. Типографика

Шрифт — **Onest** (Google Fonts, веса 400/500/600/700). Inter не используется.

| Класс | Размер / вес | Применение |
|---|---|---|
| `.h1` | 26px → 30px (≥1024px), 600 | заголовок экрана |
| `.h2` | 18px, 550 | заголовок карточки |
| `.h3` | 15.5px, 550 | подзаголовок, название сущности |
| `body` | 15px, 400 | базовый текст (16px на ≤640px) |
| `.small` | 13px | вторичный текст |
| `.tiny` | 12px | метаданные, подписи |
| `.mono` | моноширинный | номера, артикулы, домены |

Межбуквенное расстояние: `-.005em` базово, `-.025em` для `.h1`.

## 8. Требования к реализации

- Цвета только через CSS-переменные, без хардкода в компонентах.
- Состояния экрана обязательны: `data` / `loading` / `empty` / `error` (переключаются `?mock=loading|empty|error`).
- Mobile-first: проектирование от 390 px, проверка на 390 / 768 / 1440.
- Анимации — Framer Motion (stagger, scroll-triggered, hover); в прототипе CSS-переходы на `--dur` / `--ease`.
- Уважать `prefers-reduced-motion`.
