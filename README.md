# Автоматизация КП — прототип интерфейса

Дистрибьютор лабораторного оборудования и реактивов: запрос клиента → распознавание позиций →
цена из прайсов → КП → подтверждение менеджером → отправка, контроль поставщиков и клиентов,
спецификации из PO, аналитика, NEWS-рассылка.

**Главный принцип: человек в контуре.** Ничего не уходит клиенту или поставщику без
явного подтверждения менеджера.

## Что в репозитории

| Каталог | Содержимое |
|---|---|
| `prototype/` | Кликабельный прототип на моковых данных: входная страница + четыре стенда |
| `docs/` | ТЗ на интерфейс (`TZ-interfeys-avtomatizaciya-KP.md`) |
| `tools/` | Инструменты аудита кнопок и состояний (Playwright) |
| `reports/` | Отчёты по проверкам |

## Стенды

| Файл | Этап | Экраны |
|---|---|---|
| `prototype/index.html` | — | Входная страница: карточки стендов, инструкция показа, статус |
| `prototype/stand-616-e1-manager.html` | Э1 | Сегодня, Запросы, Клиенты, Ещё |
| `prototype/stand-617-e1-admin.html` | Э1 | Прайсы, Правила расчёта, Шаблоны, Пользователи, Журнал |
| `prototype/stand-619-e2.html` | Э2 | Сегодня, Воронка, Запросы, Поставщики, Календарь |
| `prototype/stand-621-e3.html` | Э3 | Спецификации, Аналитика, Рассылки, Подключения |

Прототип работает на моковых данных. Переключение состояний: `?mock=loading`,
`?mock=empty`, `?mock=error`. Тема переключается в шапке.

## Как смотреть локально

```bash
cd prototype
python3 -m http.server 8080
# открыть http://localhost:8080/
```

## Проверка

```bash
npx playwright install chromium
node tools/census.mjs 616     # перебор всех интерактивных элементов стенда
node tools/verify-hub.mjs     # входная страница: темы, состояния, переполнение
```

## Стек целевой системы

React 18 + TypeScript (strict) + Vite, Tailwind CSS + shadcn/ui, TanStack Query и Table,
React Hook Form + Zod, MSW для моков, Node.js + PostgreSQL на своём VPS. Mobile-first, 390 px.
