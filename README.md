# Автоматизация КП — прототип интерфейса

Дистрибьютор лабораторного оборудования и реактивов: запрос клиента → распознавание позиций →
цена из прайсов → КП → подтверждение менеджером → отправка, контроль поставщиков и клиентов,
спецификации из PO, аналитика, NEWS-рассылка.

**Главный принцип: человек в контуре.** Ничего не уходит клиенту или поставщику без
явного подтверждения менеджера.

## Что реализовано в едином стенде

**Таблица входящих запросов**
- Иконки в заголовках колонок, заголовки без капса — быстрее считываются.
- Числовые колонки и суммы выровнены по правому краю (табличные цифры).
- Статус — цветная «таблетка»-селект прямо в строке (цвет по тону: ok/warn/info/bad/neutral).
- Клиент в одну строку: название + домен.
- Строка раскрывается: позиции редактируются на месте (артикул, наименование, бренд,
  количество, цена поставщика), цена клиенту и сумма пересчитываются с пошлиной автоматически.
- Действия в раскрытой строке: «Открыть и доработать», «Запросить артикулы»,
  «Запросить цены», «Назначить», «Добавить позицию», «Объединить дубли».

**Письмо и КП**
- ИИ-черновик ответа клиенту с режимами «Формально» / «Короче» / «Копировать».
- Текст письма правится вручную прямо в диалоге; отправка — только после подтверждения менеджера.

**Профиль**
- Реквизиты правятся и сохраняются (localStorage), кнопка сброса демо-данных.

**Оболочка**
- Сайдбар сворачивается (248 → 68 px), состояние сохраняется.
- Mobile-first: спроектировано и проверено от 390 px, без горизонтального скролла.

**Состояния экранов**
- У каждого экрана loading / empty / error: `?mock=loading|empty|error` или переключатель в шапке.

## Единый стенд `prototype/app/stand-app.html`

Единое приложение без сборки: открывается прямо в браузере. Внутри — все роли системы
(менеджер, руководитель, администратор), светлая и тёмная темы, ИИ-помощник и демо-данные
в `localStorage` (сброс — кнопка в профиле).

**Состояния экранов:** переключатель в шапке или `?mock=loading|empty|error` — скелетоны загрузки,
пустое состояние и ошибка с кнопкой «Повторить».

**Экраны:** Сегодня · Входящие запросы (фильтры, колонки, массовые действия, экспорт) ·
Карточка запроса (письмо / позиции / КП / история) · Воронка (drag&drop с проверкой
разрешённых переходов) · Клиенты и карточка клиента · Поставщики и карточка поставщика ·
Календарь сроков · Спецификации (мастер из 3 шагов) · Аналитика · Рассылки NEWS ·
Прайсы и номенклатура (синхронизация, отчёт импорта, сопоставление колонок, матрица) ·
Правила расчёта (калькулятор) · Шаблоны (переменные, предпросмотр) · Пользователи и роли ·
Журнал действий · Подключения · Профиль · Ещё.

**Запуск локально:**
```bash
cd prototype
python3 -m http.server 8087
# затем откройте http://localhost:8087/app/stand-app.html
```

**Файлы приложения:** `data.js` (моковые данные), `ui.js` (иконки, словарь, роутер,
реестр действий, ИИ-эмуляция), `views1–3.js` (экраны), `actions.js` (обработчики всех
кнопок), `shell.js` (сайдбар, топбар, таббар, панели, диалоги), `styles.css` + `stand.css`
(дизайн-система по ТЗ, раздел 4: акцент `#B35A2A`, тёмные поверхности `#23303A`).

## Редактируемая таблица запросов

- **Живой поиск** по номеру, клиенту, домену, теме, артикулу, наименованию, бренду, поставщику
  с подсветкой совпадений (`<mark>`); очистка по Esc.
- **Раскрытие позиций прямо в строке**: состав, «нет артикула», «нет цены», сумма, быстрые действия.
- **Инлайн-правка**: статус и ответственный меняются в ячейке, с проверкой разрешённых переходов и записью в историю.
- **Пресеты-представления**: сохранение текущего фильтра под именем (localStorage), применение и удаление.
- **Счётчик активных фильтров** и блокировка кнопки «Сбросить», когда фильтров нет.

## Редактирование письма и ИИ-редактор

- **Черновик письма**: ручной редактор (`Редактировать текст`), бейдж «Черновик письма», возврат «К оригиналу».
- **ИИ-редактор письма**: 5 режимов (Улучшить / Сократить / Официальный тон / Перевести / Проверить артикулы),
  diff «до/после» (`<del>` / `<ins>`), кнопки «Применить» и «Оставить как было».
- **Оригинал письма** — отдельный диалог только для чтения, с вложениями и пометкой о санитизации HTML.
