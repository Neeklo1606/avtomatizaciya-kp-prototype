# Автоматизация КП — прототип интерфейса

Дистрибьютор лабораторного оборудования и реактивов: запрос клиента → распознавание позиций →
цена из прайсов → КП → подтверждение менеджером → отправка, контроль поставщиков и клиентов,
спецификации из PO, аналитика, NEWS-рассылка.

**Главный принцип: человек в контуре.** Ничего не уходит клиенту или поставщику без
явного подтверждения менеджера.

## Что в репозитории

| Каталог | Содержимое |

## Единый стенд `prototype/app/stand-app.html`

Единое приложение без сборки: открывается прямо в браузере. Внутри — все роли системы
(менеджер, руководитель, администратор), светлая и тёмная темы, ИИ-помощник и демо-данные
в `localStorage` (сброс — кнопка в профиле).

**Экраны:** Сегодня · Входящие запросы (фильтры, колонки, массовые действия, экспорт) ·
Карточка запроса (письмо / позиции / КП / история) · Воронка (drag&drop с проверкой
разрешённых переходов) · Клиенты и карточка клиента · Поставщики и карточка поставщика ·
Календарь сроков · Спецификации (мастер из 3 шагов) · Аналитика · Рассылки NEWS ·
Прайсы и номенклатура (синхронизация, отчёт импорта, сопоставление колонок, матрица) ·
Правила расчёта (калькулятор) · Шаблоны (переменные, предпросмотр) · Пользователи и роли ·
Журнал действий · Подключения · Профиль · Ещё.

**Запуск локально:**
```bash
cd prototype
python3 -m http.server 8087
# затем откройте http://localhost:8087/app/stand-app.html
```

**Файлы приложения:** `data.js` (моковые данные), `ui.js` (иконки, словарь, роутер,
реестр действий, ИИ-эмуляция), `views1–3.js` (экраны), `actions.js` (обработчики всех
кнопок), `shell.js` (сайдбар, топбар, таббар, панели, диалоги), `styles.css` + `stand.css`
(дизайн-система по ТЗ, раздел 4: акцент `#B35A2A`, тёмные поверхности `#23303A`).

## Как смотреть локально

```bash
# открыть http://localhost:8080/
```

## Проверка

```bash
npx playwright install chromium
node tools/census.mjs 616     # перебор всех интерактивных элементов стенда
node tools/verify-hub.mjs     # входная страница: темы, состояния, переполнение
```

## Стек целевой системы

React 18 + TypeScript (strict) + Vite, Tailwind CSS + shadcn/ui, TanStack Query и Table,
React Hook Form + Zod, MSW для моков, Node.js + PostgreSQL на своём VPS. Mobile-first, 390 px.
